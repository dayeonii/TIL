## 📖 이 레포에 대해서

이 레포는 매일 공부한 내용을 기록하고 복습하는 **TIL(Today I Learned) 저장소**입니다.

완성된 글을 작성하는 것보다,  
그날 배운 내용과 새롭게 이해한 것, 헷갈렸던 부분을 기록하고  
다시 돌아보며 학습 내용을 정리하는 것을 목표로 합니다.

### 기록 원칙

- 매일 공부한 내용을 기록한다.
- 완벽하게 이해하지 못한 내용도 기록한다.
- 복습하면서 새롭게 이해한 내용은 기존 기록에 보완한다.
- 기록을 위한 기록이 되지 않도록, 적어도 하나의 내용을 제대로 돌아본다.
- 충분히 이해하고 정리할 가치가 있는 내용은 기술 블로그에 다시 정리한다.
