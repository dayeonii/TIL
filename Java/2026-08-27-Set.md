# Set
- 중복 값을 허용하지 않음
- 원소의 저장 순서가 없음
- 구현 방법
    - HashSet
        
        `HashSet<T> hs = new HashSet<>();`
        
    - TreeSet : 정렬 기능이 추가된 형태 (이진 탐색 트리)
        
        `TreeSet<T> ts = new TreeSet<>();`
        
- 이번 문제에서 HashSet<Point> 를 사용 → 커스텀 클래스 타입
    - So, `hashCode()`와 `equals()`를 오버라이딩 해주어야 함
 
## 코드 예제
### 기본 사용법
```java
import java.util.HashSet;
import java.util.Set;

public class SetExample {
    public static void main(String[] args) {
        // Set 선언 및 생성
        Set<String> set = new HashSet<>();

        // 데이터 추가 (add)
        set.add("사과");
        set.add("바나나");
        set.add("포도");
        set.add("사과"); // 중복 데이터: 무시됨

        // 출력 (순서가 보장되지 않음)
        System.out.println("Set 내용: " + set); // [포도, 사과, 바나나] (순서 랜덤)

        // 요소 존재 여부 확인 (contains)
        if (set.contains("바나나")) {
            System.out.println("바나나가 존재합니다.");
        }

        // 요소 삭제 (remove)
        set.remove("포도");

        // 순회 (for-each문)
        for (String item : set) {
            System.out.println("과일: " + item);
        }

        // 크기 확인 및 전체 삭제
        System.out.println("크기: " + set.size());
        set.clear();
        System.out.println("비어있는지 확인: " + set.isEmpty());
    }
}
```

### LinkedHashSet : 입력 순서를 유지하는 Set
```java
import java.util.LinkedHashSet;
import java.util.Set;

Set<String> linkedSet = new LinkedHashSet<>();
linkedSet.add("첫째");
linkedSet.add("둘째");
linkedSet.add("셋째");

// 입력한 순서대로 출력: [첫째, 둘째, 셋째]
System.out.println(linkedSet);
```

### TreeSet : 이진트리를 이용한 정렬 Set
```java
import java.util.Set;
import java.util.TreeSet;

Set<Integer> treeSet = new TreeSet<>();
treeSet.add(50);
treeSet.add(10);
treeSet.add(30);

// 오름차순으로 자동 정렬되어 출력: [10, 30, 50]
System.out.println(treeSet);
```

### List->Set : List의 원소에 대해 중복 제거 처리
```java
import java.util.Arrays;
import java.util.HashSet;
import java.util.List;
import java.util.Set;

List<String> listWithDuplicates = Arrays.asList("A", "B", "A", "C", "B");
// List를 Set으로 변환하여 중복 즉시 제거
Set<String> uniqueSet = new HashSet<>(listWithDuplicates); 

System.out.println(uniqueSet); // [A, B, C]
```
